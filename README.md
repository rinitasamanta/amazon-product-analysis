# Amazon Product Analysis Using Python

## Project Overview

This project analyzes Amazon product data using Python to identify patterns in pricing, discounts, customer ratings, and customer engagement.

## Business Objective

The objective is to analyze product-level data and generate useful business insights that can support pricing, discount, product performance, and customer engagement decisions.

## Dataset

The dataset contains Amazon product information including:

- Product Name
- Category
- Actual Price
- Discounted Price
- Discount Percentage
- Rating
- Rating Count
- Customer Reviews

## Tools & Technologies

- Python
- Pandas
- NumPy
- Matplotlib
- Google Colab

## Analysis Performed

- Data Cleaning
- Data Quality Analysis
- Price Analysis
- Discount Analysis
- Category Analysis
- Rating Analysis
- Customer Engagement Analysis
- Relationship Analysis
- Business Insights
- Business Recommendations

## Key Business Areas

The analysis focuses on:

- Product pricing patterns
- Discount strategies
- Product ratings
- Customer engagement
- Category performance
- Relationship between discounts, prices, and ratings

## Conclusion

The analysis provides data-driven insights that can help businesses understand product performance, customer preferences, pricing patterns, and discount strategies.
